# Лабораторна робота: Програмування циклічних алгоритмів

Виконав: Шевченко Нікіта Вікторович, група ІСТ-21, варіант 17 (додатковий варіант: 17 + 5 = 22).

## Структура репозиторію

* task1.cpp — обчислення значень функції $y = \sin(x) + |5x - 1.5|$ для 5 значень аргументу x (for)
* task2.cpp — обчислення суми та середнього арифметичного квадратних коренів чисел (for)
* task3.cpp — табулювання функції $y = 8 + \frac{\sqrt{x - 7}}{x + 5}$ на відрізку [a, b] з кроком h та перевіркою ОДЗ (while)
* task5_v7.cpp — розкладання натурального числа на цифри та знаходження суми непарних цифр, більших за 2 (while, варіант 7)
* png — блок-схема алгоритму для Завдання 5 (побудована в draw.io)

## Компіляція та запуск

`bash
g++ task1.cpp -o task1 -lm
./task1

g++ task2.cpp -o task2 -lm
./task2

g++ task3.cpp -o task3 -lm
./task3

g++ task5_v7.cpp -o task5_v7
./task5_v7
